# Calibration Fixes Confidence, Not Prediction Sets: An Empirical Comparison of Temperature Scaling, Ensembling, and Conformal Score Choice for LLM-Style Classifiers

## Abstract

Probabilistic uncertainty quantification for large language models (LLMs) is an active research area, with recent work exploring verbalized confidence, self-consistency sampling, temperature-based calibration, and conformal prediction as ways to produce trustworthy confidence estimates. A recurring open question is how these techniques interact: does fixing pointwise calibration (e.g., via temperature scaling) actually improve the *downstream* guarantees people care about, such as conformal prediction-set size? We study this empirically in a controlled setting, using a synthetic surrogate classifier (a small MLP on a noisy, class-overlapping 6-way task) since this sandbox has no internet access to fetch a pretrained LLM, evaluated with the tools used in the LLM calibration literature (ECE, temperature scaling, deep ensembles as a self-consistency proxy, split conformal prediction with LAC and APS scores). Averaged over 10 independent seeds (data draws, model inits) we find that (1) temperature scaling reliably collapses ECE (0.139→0.010, effect >10x the seed-to-seed std), (2) ensembling alone does not fix calibration and is at best a noisy, unreliable fix, (3) calibration method changes LAC conformal set size by an amount indistinguishable from seed noise, while it changes APS set size by a robust ~0.55 classes, and (4) switching the nonconformity score from LAC to APS changes set size by ~1.9-2.5 classes — larger than the APS calibration effect by roughly 3-5x under our default data settings. Critically, a sensitivity sweep over label noise and class overlap shows this ranking is *not* universal: at low class overlap (σ=1.2), the calibration effect on APS set size (2.43 classes) exceeds the score-choice effect (1.74 classes), reversing the paper's headline ordering. We report this boundary condition explicitly rather than the single-config point estimate that would otherwise overstate the generality of the finding.

## 1. Introduction

As LLMs are deployed in higher-stakes settings, there is growing interest in equipping their outputs with calibrated confidence or formal uncertainty guarantees. Three families of methods dominate recent work: (1) **confidence estimation** — softmax probabilities, verbalized confidence, and self-consistency sampling, which a 2025 survey (Huang et al., arXiv:2503.15850) notes is often poorly calibrated; (2) **post-hoc calibration**, principally temperature scaling (Guo et al., 2017), still a standard baseline in 2025-26 LLM work (arXiv:2603.09309, arXiv:2604.19444); and (3) **conformal prediction (CP)**, which wraps any confidence function in a distribution-free procedure with finite-sample marginal coverage regardless of calibration quality (e.g., SConU arXiv:2504.14154, domain-shift-aware CP arXiv:2510.05566). A key selling point repeated across this literature is that CP's coverage guarantee holds even for a badly calibrated model — but papers rarely quantify how much calibration quality affects the *efficiency* (set size) of the resulting sets, or how that compares to the effect of nonconformity-score choice (LAC vs. APS).

**Gap.** No paper we found directly cross-tabulates calibration method against conformal score choice to ask which factor matters more for prediction-set size, or checks whether that ranking is stable across problem difficulty. This is the gap we target.

**Our contribution.** A small, fully-reproducible empirical study, run across 10 seeds, that: (a) reproduces the standard finding that temperature scaling fixes ECE while ensembling alone does not, robustly; (b) shows calibration method has a small-to-moderate effect on conformal set size that is score-dependent (negligible for LAC, real but modest for APS); (c) shows the score-choice effect (LAC vs. APS) dominates calibration effects under our default synthetic settings, but (d) — new in this revision — a noise/overlap sensitivity sweep shows this dominance is not universal and can reverse under low class overlap. We also document a floor effect in LAC (average set size is *below 1 class*, meaning most points get 0 or 1 labels, so headline "set size" differences of a few thousandths are mechanically small) and a failure mode (empty prediction sets for ~9-10% of test points at nominal 90% coverage) that is invisible if one only reports mean coverage.

**Honesty about scope.** We do not use a pretrained LLM: HuggingFace Hub access in this environment fails with a certificate error (no outbound internet). We use a small feedforward network trained on a synthetic, class-overlapping, label-noised task designed to reproduce measurable softmax miscalibration, evaluated with the exact tool stack used in the LLM literature we surveyed. We treat this as a controlled surrogate, not a claim about any specific LLM's behavior.

## 2. Method

### 2.1 Synthetic task
Six classes in a 20-dimensional feature space, generated from fixed class-specific Gaussian means with per-sample isotropic noise (σ=1.8 default) inducing class overlap. Training labels are corrupted with 12% uniform label noise (default) to induce memorization-driven miscalibration (Guo et al., 2017). Calibration/test labels are noise-free. Split: 4,000 train / 1,500 calibration / 1,500 test.

### 2.2 Models
- **Base model**: 2-hidden-layer MLP (64 units, ReLU), 80 epochs full-batch Adam.
- **Ensemble**: 5 MLPs, each on an independent bootstrap resample with a different init, combined by averaging softmax outputs — a lightweight surrogate for self-consistency sampling (diversity via bootstrap/init rather than stochastic decoding; the aggregation mechanism is analogous, not identical).

### 2.3 Calibration methods
`raw_softmax` (T=1), `temp_scaled` (T fit by NLL minimization via LBFGS on the calibration split, Guo et al. 2017), `ensemble` (5-model average, T=1), `ensemble_temp_scaled` (T fit on the ensemble's averaged logits). Metrics: accuracy, NLL, Brier, 15-bin ECE.

### 2.4 Conformal prediction
Split conformal on the calibration set, target coverage 90% (α=0.10), evaluated on held-out test data, for **LAC** (score = 1 − p(true class); set = {classes with p ≥ 1 − q̂}) and **APS** (Romano et al. 2020; score = cumulative sorted softmax mass through the true class; set = smallest sorted prefix with cumulative mass ≤ q̂, top class always included). We report coverage, average set size, and empty-set fraction.

### 2.5 Multi-seed protocol and sensitivity sweep (new in this revision)
Reviewers of the previous version correctly noted that all results came from a single seed, that a Section-3.4 arithmetic error understated the true LAC calibration-effect spread and thus its ratio to the score-choice effect, and that no sensitivity analysis was run over the synthetic task's difficulty parameters. We address all three: (1) we repeat the full pipeline (class means, data draws, model init, bootstrap resampling) across 10 independent seeds and report mean ± std for every headline number; (2) we recompute the Section 3.4 comparison from these multi-seed numbers rather than a single run; (3) we sweep label noise ∈ {0.00, 0.12, 0.24} and class-overlap σ ∈ {1.2, 1.8, 2.4} (3 seeds each) to test whether the score-choice-dominates ranking is stable. All code and raw outputs (`experiment.py`, `multiseed_experiment.py`, `sweep_experiment.py`, `results*.json`) are included.

## 3. Results

### 3.1 Calibration quality (10 seeds, mean ± std)

| Method | Accuracy | ECE | Fitted T |
|---|---|---|---|
| raw_softmax | 0.970±0.008 | **0.139±0.009** | 1.0 |
| temp_scaled | 0.970±0.008 | **0.010±0.004** | 0.375±0.034 |
| ensemble | 0.973±0.008 | **0.144±0.009** | 1.0 |
| ensemble_temp_scaled | 0.973±0.009 | **0.015±0.006** | 0.381±0.034 |

Temperature scaling reduces ECE by ~13x, and the effect size (0.13) is more than 10 standard deviations larger than the seed-to-seed noise (std ≈ 0.009) — this is a robust finding. The fitted temperature is consistently < 1 across all 10 seeds (mean 0.375-0.381, std 0.034), confirming our base model is systematically **underconfident** (the opposite of the classic Guo et al. 2017 overconfidence story), robustly across seeds and, per §3.4 below, across the noise/overlap sweep too. **Ensembling's effect on ECE is directionally consistent with worsening calibration (0.139→0.144) but the 0.005 gap is smaller than one seed-to-seed standard deviation (0.009)** — in the single-run version of this paper we called this a robust worsening effect; with 10 seeds we retract that specific claim. The defensible claim is narrower: ensembling does not fix calibration, and unlike temperature scaling, its effect on ECE is not distinguishable from noise in our data.

### 3.2 Conformal prediction: LAC (10 seeds)

| Method | Coverage | Avg. set size | Empty-set frac. |
|---|---|---|---|
| raw_softmax | 0.900±0.005 | 0.908±0.008 | 0.092±0.008 |
| temp_scaled | 0.901±0.008 | 0.907±0.011 | 0.093±0.011 |
| ensemble | 0.897±0.009 | 0.902±0.012 | 0.098±0.012 |
| ensemble_temp_scaled | 0.901±0.007 | 0.907±0.011 | 0.093±0.011 |

Coverage lands within noise of the 90% target for all four methods, as CP theory guarantees regardless of calibration quality. Average LAC set size ranges only 0.902-0.908 across methods differing 13x in ECE — a spread of 0.006, well *inside* the ±0.008-0.012 seed noise band. **We can no longer claim (as the previous version did with a single seed) that calibration method measurably changes LAC set size; the honest statement is that it does not detectably do so.** All variants remain in a near-degenerate regime: mean set size < 1, so most points get either 0 or exactly 1 predicted label, and 9.2-9.8% of test points get an *empty* set at nominal 90% coverage — a real, seed-robust cost hidden by the coverage number alone.

### 3.3 Conformal prediction: APS (10 seeds)

| Method | Coverage | Avg. set size |
|---|---|---|
| raw_softmax | 0.9997 | 2.838±0.120 |
| temp_scaled | 0.9999 | 3.389±0.123 |
| ensemble | 0.9997 | 2.785±0.126 |
| ensemble_temp_scaled | 0.9999 | 3.333±0.136 |

APS never produces empty sets (by construction) but over-covers (~100% vs. 90% target) with much larger sets (2.8-3.4 of 6 classes). Unlike LAC, the calibration effect here **is** robust: temperature scaling increases average set size by ~0.55 classes for both the base model and the ensemble, a shift ~4x larger than the seed std (0.12-0.14) — sharpening confidence via T<1 changes the cumulative-mass ranking APS relies on, adding classes rather than removing them.

### 3.4 Cross-cutting comparison (corrected)

A reviewer of the previous version caught an arithmetic error: we had stated the LAC calibration-method spread was "at most 0.03," which was ~3x too large relative to that run's own numbers, and this error propagated into an inflated "4-60x" headline ratio. Recomputed from the 10-seed means: the **LAC calibration effect is ≈0.006, statistically indistinguishable from zero** (smaller than its own seed-to-seed std), so reporting a ratio against it is not meaningful — the LAC story is simply "no detectable effect," not "a small but nonzero effect." The **APS calibration effect is a robust ≈0.55 classes**. The **score-switch effect (LAC→APS, same calibration method)** ranges **1.88-2.48 classes** across the four methods. Comparing the two effects that are both statistically real: score-switch is **~3.4-4.5x** the robust APS calibration effect — smaller than the erroneous "4-60x" figure in v1, but still a clear, one-directional dominance under our default synthetic settings (σ=1.8, 12% label noise).

### 3.5 Sensitivity sweep: is score-choice dominance universal?

| Config | Calib. effect (LAC) | Calib. effect (APS) | Score-switch effect |
|---|---|---|---|
| noise=0.00 | 0.001 | 0.123 | 2.123 |
| noise=0.12 (default) | 0.000 | 0.512 | 1.983 |
| noise=0.24 | 0.000 | 1.074 | 1.552 |
| σ=1.2 (low overlap) | 0.036 | **2.425** | **1.741** |
| σ=1.8 (default) | 0.000 | 0.512 | 1.983 |
| σ=2.4 (high overlap) | 0.004 | 0.386 | 1.866 |

Two things move with difficulty. First, as label noise increases, the score-switch effect *shrinks* (2.12→1.55 classes) while the APS calibration effect *grows* (0.12→1.07), narrowing the gap between them. Second, and more strikingly, at **low class overlap (σ=1.2)** — a setting closer to an easy, well-separated classification task — the APS calibration effect (2.43 classes) **exceeds** the score-switch effect (1.74 classes), reversing the paper's headline ordering. Inspection shows this is because low overlap drives near-deterministic softmax outputs, so temperature scaling has an outsized effect on the cumulative-mass ranking APS uses, ballooning its sets (raw 2.64 → temp-scaled 5.07 of 6 classes). **The takeaway is narrower than v1's Discussion suggested: nonconformity-score choice dominates calibration-method choice for our default, moderately-overlapping synthetic task, but this ranking is itself a function of task difficulty and is not guaranteed to hold in general** — a caveat any transfer of this finding to a specific LLM/dataset should check empirically rather than assume.

## 4. Discussion and Limitations

The central finding — that score choice matters more than calibration method for LAC and, under our default settings, more than the *robust* part of the calibration effect on APS — helps explain why LLM-focused CP papers invest in nonconformity-score design over upstream calibration. But §3.5 shows this is a difficulty-dependent empirical regularity, not a law: it can invert under low class overlap. We flag this explicitly, rather than let the single-configuration finding of v1 stand as if it were general.

Remaining limitations: (1) we still cannot run against an actual pretrained LLM (HuggingFace Hub SSL failure in this sandbox); the procedural claims (CP coverage is calibration-robust; LAC vs. APS differ sharply in conservativeness/emptiness) are properties of the conformal machinery itself and should transfer, but exact numbers and the score-dominance ranking are specific to this synthetic family and its difficulty regime, per §3.5. (2) We did not implement regularized APS (RAPS), which is commonly used to control APS's large sets; whether RAPS closes the gap with LAC while retaining APS's no-empty-set property is open. (3) Our self-consistency-via-bootstrap-ensembling analogy is acknowledged as imperfect — real self-consistency draws diversity from stochastic decoding, not bootstrap/init variation. (4) The sweep in §3.5 varies noise and overlap but not target coverage level (fixed at 90%) or number of classes (fixed at 6); both remain open sensitivity questions, especially given LLM MCQA tasks often have far more answer options.

## 5. Conclusion

With 10-seed replication, temperature scaling remains a robust ECE fix (13x reduction, effect ≫ seed noise) while naive ensembling does not reliably help and may mildly hurt calibration, though we retract v1's claim that the latter is itself a robust effect. Calibration method has no detectable effect on LAC conformal set size but a real, seed-robust ~0.55-class effect on APS set size. Switching LAC→APS changes set size by ~1.9-2.5 classes — larger than the robust APS calibration effect by ~3-5x under our default settings (corrected from v1's erroneous "4-60x," an error a reviewer caught and we verified). Critically, this dominance is not universal: a noise/overlap sensitivity sweep shows it can reverse at low class overlap, where calibration choice affects APS set size more than the score switch does. Practitioners building LLM systems around conformal guarantees should still prioritize nonconformity-score selection and check empty-set rates (LAC empties 9-10% of points here even at nominal coverage) over calibration quality alone — but should verify this ranking on their own task rather than assume it transfers, since it depends measurably on how separable the underlying classes are.
