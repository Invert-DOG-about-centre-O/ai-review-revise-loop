# Calibration Fixes Confidence, Not Prediction Sets: An Empirical Comparison of Temperature Scaling, Ensembling, and Conformal Score Choice for LLM-Style Classifiers

## Abstract

Probabilistic uncertainty quantification for large language models (LLMs) is an active research area, with recent work exploring verbalized confidence, self-consistency sampling, temperature-based calibration, and conformal prediction as ways to produce trustworthy confidence estimates. A recurring open question is how these techniques interact: does fixing pointwise calibration (e.g., via temperature scaling) actually improve the *downstream* guarantees people care about, such as conformal prediction-set size? We study this empirically in a controlled setting. Since this sandbox has no internet access to download a pretrained LLM, we construct a synthetic surrogate: a small MLP classifier trained on a noisy, class-overlapping 6-way classification task, evaluated with the same tools used in the LLM calibration literature (Expected Calibration Error, temperature scaling, deep ensembles as a self-consistency proxy, and split conformal prediction with both LAC and APS nonconformity scores). We find that (1) temperature scaling nearly eliminates calibration error (ECE drops from 0.134 to 0.015) and (2) ensembling alone does *not* fix calibration and can even slightly worsen it, but (3) neither method meaningfully changes conformal prediction-set size under the LAC score, while (4) the choice between LAC and APS conformal scores has a dramatically larger effect on set size (0.91 vs. ~2.9 classes per set, respectively) than either calibration method. This suggests that for practitioners deploying LLMs with conformal guarantees, the choice of nonconformity score dominates the choice of calibration method — a distinction that is easy to lose in survey-level treatments that discuss calibration and conformal prediction as parallel, interchangeable remedies for the same problem.

## 1. Introduction

As LLMs are deployed in higher-stakes settings, there is growing interest in equipping their outputs with calibrated confidence or formal uncertainty guarantees. Three families of methods dominate recent work:

1. **Confidence estimation.** LLMs can report confidence via token-level softmax probabilities, verbalized statements ("I am 80% confident"), or sampling-based self-consistency (agreement across multiple stochastic generations). A 2025 survey on uncertainty quantification and confidence calibration in LLMs (Huang et al., arXiv:2503.15850) catalogs these approaches and notes that verbalized confidence is often poorly calibrated and, for RLHF-tuned models, frequently *worse* than raw token probabilities. Work on calibrating verbalized probabilities (arXiv:2410.06707) and on aligning verbalized with internal confidence (arXiv:2512.11998) both treat this gap as a central open problem.

2. **Post-hoc calibration.** Temperature scaling (Guo et al., 2017) rescales logits by a scalar fit on held-out data to minimize NLL, and remains a standard baseline even for LLM confidence calibration work in 2025 (e.g., arXiv:2603.09309 on confidence-scale design, arXiv:2604.19444 on unsupervised calibration for reasoning models).

3. **Conformal prediction (CP).** CP wraps any confidence function in a distribution-free procedure that produces prediction *sets* with a finite-sample marginal coverage guarantee, regardless of whether the underlying scores are well-calibrated. Recent LLM-specific work includes selective conformal uncertainty (SConU, arXiv:2504.14154 / ACL 2025), domain-shift-aware conformal prediction (arXiv:2510.05566), and conformal prediction for multiple-choice QA (MIT Media Lab). A key selling point repeated across this literature is that CP's coverage guarantee holds *even for a badly calibrated model* — but papers rarely quantify how much calibration quality affects the *efficiency* (set size) of the resulting sets, or how the choice of nonconformity score (e.g., LAC vs. APS) compares in magnitude to calibration effects.

**Gap.** No paper we found directly cross-tabulates calibration method (raw vs. temperature-scaled vs. ensembled) against conformal score choice (LAC vs. APS) to ask which factor matters more for the practically-relevant outcome (prediction set size at fixed coverage). This is the gap we target.

**Our contribution.** A small, fully-reproducible empirical study (runs in under 5 seconds on CPU) that: (a) reproduces the standard finding that temperature scaling fixes ECE while ensembling alone does not; (b) shows both have a *small* effect on LAC conformal set size relative to (c) the *large* effect of switching the nonconformity score from LAC to APS. We also document a failure mode of LAC (empty prediction sets for ~8-9% of test points even at nominal 90% coverage) that is masked if one only reports mean coverage.

**Honesty about scope.** We do not use a pretrained LLM: HuggingFace Hub access in this environment fails with a certificate error (no outbound internet). We instead use a small feedforward network trained on a synthetic, class-overlapping, label-noised classification task, explicitly designed to reproduce the property that matters for this study — a model whose softmax confidence is measurably miscalibrated relative to its accuracy — and we evaluate it with the exact tool stack (ECE, temperature scaling, ensembling, split conformal) used in the LLM literature we surveyed. We treat this as a controlled surrogate for the LLM setting, not a claim about any specific LLM's behavior, and flag this as the main limitation.

## 2. Method

### 2.1 Synthetic task
Six classes in a 20-dimensional feature space, generated from class-specific Gaussian means (drawn once, fixed) with per-sample isotropic noise (σ=1.8) that induces genuine class overlap. Training labels are corrupted with 12% uniform label noise to induce memorization-driven miscalibration, a widely used recipe for producing overconfident deep classifiers (Guo et al., 2017). Calibration and test labels are noise-free. Split: 4,000 train / 1,500 calibration / 1,500 test.

### 2.2 Models
- **Base model**: one 2-hidden-layer MLP (64 units, ReLU), trained 80 epochs full-batch Adam on the noisy training set.
- **Ensemble**: 5 MLPs of the same architecture, each trained on an independent bootstrap resample of the training set with a different random initialization, and combined by averaging softmax outputs. This serves as a lightweight surrogate for **self-consistency** sampling in LLMs, where diversity comes from stochastic decoding rather than bootstrap/init diversity — the aggregation mechanism (averaging independent estimates of the output distribution) is analogous.

### 2.3 Calibration methods compared
1. `raw_softmax` — base model, T=1.
2. `temp_scaled` — base model, temperature T fit by minimizing NLL on the calibration split via LBFGS (Guo et al., 2017).
3. `ensemble` — 5-model average, T=1.
4. `ensemble_temp_scaled` — 5-model average, temperature fit the same way on the ensemble's averaged logits.

Metrics: accuracy, NLL, Brier score, and 15-bin Expected Calibration Error (ECE).

### 2.4 Conformal prediction
Split conformal prediction on the calibration set, target coverage 90% (α=0.10), evaluated on the held-out test set, using two nonconformity scores applied to *each* of the four confidence methods above:
- **LAC** (least-ambiguous-set classifier): score = 1 − p(true class); prediction set = {classes with p ≥ 1 − q̂}.
- **APS** (Adaptive Prediction Sets, Romano et al. 2020): score = cumulative softmax mass up to and including the true class in sorted order; prediction set = smallest sorted prefix whose cumulative mass ≤ q̂ (top class always included).

We report empirical coverage, average set size, and the fraction of empty prediction sets (only possible under LAC).

## 3. Results

All numbers below are from a single run (`experiment.py` → `results.json`); code and raw logs are included in this directory.

### 3.1 Calibration quality

| Method | Accuracy | NLL | Brier | ECE | Mean confidence |
|---|---|---|---|---|---|
| raw_softmax | 0.959 | 0.238 | 0.093 | **0.134** | 0.828 |
| temp_scaled (T=0.451) | 0.959 | 0.109 | 0.056 | **0.015** | 0.955 |
| ensemble | 0.967 | 0.254 | 0.097 | **0.153** | 0.814 |
| ensemble_temp_scaled (T=0.409) | 0.966 | 0.108 | 0.056 | **0.017** | 0.953 |

Temperature scaling reduces ECE by ~9x for both the single model and the ensemble. Notably the fitted temperature is *less than 1* (T≈0.45), meaning our base model is **underconfident** (mean confidence 0.83 vs. accuracy 0.96) rather than overconfident — the opposite of the classic Guo et al. (2017) finding for large modern vision nets, though consistent with reports that some calibration interventions on noisy data can push miscalibration in either direction. Critically, **ensembling alone does not improve — and slightly worsens — ECE** (0.134 → 0.153), even though it modestly improves raw accuracy (+0.7pp) and NLL/Brier are roughly unchanged. This is a direct empirical counterpoint to treating self-consistency-style aggregation as a calibration fix: in our setting it is orthogonal to calibration and must be paired with an explicit calibration step (temperature scaling) to yield well-calibrated probabilities.

### 3.2 Conformal prediction: LAC

| Method | q̂ | Coverage | Avg. set size | Empty-set frac. |
|---|---|---|---|---|
| raw_softmax | 0.459 | 0.909 | 0.920 | 0.080 |
| temp_scaled | 0.179 | 0.900 | 0.911 | 0.089 |
| ensemble | 0.456 | 0.903 | 0.916 | 0.084 |
| ensemble_temp_scaled | 0.186 | 0.902 | 0.913 | 0.087 |

All four methods hit the target 90% marginal coverage almost exactly (as CP theory guarantees, independent of calibration quality) — coverage ranges only 0.900–0.909 across methods that differ in ECE by 9x. Average set size is essentially flat across methods (0.911–0.920) despite the large calibration differences. This confirms, empirically, the standard CP claim that coverage is robust to the underlying score's calibration — but it also shows that **set-size efficiency barely benefits from calibration either**, at least for LAC on this task. All four LAC variants produce **empty prediction sets for 8.0–8.9% of test points** — i.e., at 90% nominal coverage, roughly 1 in 12 points get *no* predicted label at all, which is a legitimate but easy-to-miss consequence of the LAC score (it can produce empty sets when p(argmax) < 1 − q̂). This nuance is not visible from the coverage number alone.

### 3.3 Conformal prediction: APS

| Method | q̂ | Coverage | Avg. set size | Empty-set frac. |
|---|---|---|---|---|
| raw_softmax | 0.976 | 0.999 | 2.744 | 0.000 |
| temp_scaled | 1.000 | 1.000 | 3.087 | 0.000 |
| ensemble | 0.968 | 0.999 | 2.715 | 0.000 |
| ensemble_temp_scaled | 1.000 | 1.000 | 3.241 | 0.000 |

APS never produces empty sets (by construction) but is markedly more conservative here: coverage is ~100% (over-covering the 90% target) and average set size is **2.7–3.2 out of 6 classes** — roughly 3–3.5x larger than LAC's sets. Within APS, temperature-scaled variants produce slightly *larger* sets than their raw counterparts (2.74→3.09 for the base model, 2.71→3.24 for the ensemble), because sharpening low-confidence tails via T<1 changes the cumulative-mass ranking used by APS in a way that, on this task, adds classes rather than removing them.

### 3.4 Cross-cutting comparison

Holding the nonconformity score fixed and varying calibration method changes average set size by at most **0.03 (LAC)** or **0.53 (APS)** classes. Holding calibration method fixed and switching LAC→APS changes average set size by **1.8–2.3 classes** — 4–60x larger than any calibration effect we measured. The score-choice effect dominates.

## 4. Discussion and Limitations

The central empirical finding — that conformal score choice matters far more than calibration method for prediction-set efficiency — is consistent with, and helps explain, why LLM-focused CP papers (SConU, domain-shift-aware CP) invest heavily in designing better nonconformity scores rather than in upstream calibration. It also surfaces a caveat (LAC's empty-set rate) that is straightforward to check but easy to omit when only marginal coverage is reported.

The main limitation is that we could not run this study against an actual pretrained LLM due to lack of internet access in the execution sandbox (HuggingFace Hub requests fail with SSL certificate errors); all experiments use a synthetic surrogate classifier chosen to reproduce measurable softmax miscalibration under a controlled, known data-generating process. The qualitative pattern (CP coverage is calibration-robust; LAC vs. APS differs sharply in conservativeness and empty-set behavior) is a property of the *conformal procedures themselves*, which are model-agnostic by construction, so we expect the qualitative ranking to transfer to token-probability-based LLM confidence scores, but the specific numbers (ECE values, set sizes) are specific to this synthetic task and should not be read as LLM benchmarks. Future work with actual model access should replicate Section 3 on real multiple-choice QA log-likelihoods (e.g., following the MIT Media Lab MCQA-CP setup) to confirm the relative magnitude of the score-choice vs. calibration-method effect.

## 5. Conclusion

Temperature scaling reliably fixes pointwise calibration error (9x ECE reduction here) while naive ensembling/self-consistency-style averaging does not, and can mildly hurt it. Yet neither calibration intervention meaningfully changes conformal prediction set size — the choice of nonconformity score (LAC vs. APS) has a 4–60x larger effect on set size in our experiments, and LAC's tendency to emit empty sets for ~8% of points at nominal 90% coverage is a real cost that raw coverage numbers hide. Practitioners building LLM systems around conformal guarantees should prioritize nonconformity-score selection (and check empty-set rates) over investing purely in calibration quality, since coverage validity is calibration-agnostic by construction but efficiency and set-emptiness are not.
