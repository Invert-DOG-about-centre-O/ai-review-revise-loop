# Calibration Fixes Confidence, Not Prediction Sets: An Empirical Comparison of Temperature Scaling, Ensembling, and Conformal Score Choice for LLM-Style Classifiers

## Abstract

Probabilistic uncertainty quantification for large language models (LLMs) is an active research area, with recent work exploring verbalized confidence, self-consistency sampling, temperature-based calibration, and conformal prediction as ways to produce trustworthy confidence estimates. A recurring open question is how these techniques interact: does fixing pointwise calibration (e.g., via temperature scaling) actually improve the *downstream* guarantee people care about — conformal prediction-set size? We study this empirically in a controlled setting. Since this sandbox has no internet access to download a pretrained LLM, we construct a synthetic surrogate: a small MLP classifier on a noisy, class-overlapping 6-way task, evaluated with the same tools used in the LLM calibration literature (ECE, temperature scaling, deep ensembles as a self-consistency proxy, and split conformal prediction with LAC and APS scores). To guard against seed-level noise — a gap in our earlier draft — every number below is a mean ± standard deviation over **10 independent seeds** (fresh data draw, model init, and bootstrap resample each time). We find that (1) temperature scaling reduces ECE by ~40% (0.128±0.008 → 0.078±0.004); (2) ensembling alone does *not* fix calibration (0.131±0.008, indistinguishable from, not reliably worse than, the base model); (3) calibration method changes LAC conformal set size by ≈0.004, *smaller than one seed-to-seed standard deviation* (≈0.01) — not distinguishable from noise; while (4) switching the score from LAC to APS changes set size by ≈1.8 classes (0.90±0.01 vs. 2.6–2.8±0.08), roughly 20+ standard deviations, a gap that survives even in a low-noise regime where the base model is already near-calibrated. For practitioners deploying LLMs with conformal guarantees, nonconformity-score choice dominates calibration method — a distinction easy to lose in survey-level treatments that discuss the two as parallel, interchangeable remedies.

## 1. Introduction

As LLMs are deployed in higher-stakes settings, there is growing interest in equipping their outputs with calibrated confidence or formal uncertainty guarantees. Three families of methods dominate recent work: (1) **confidence estimation** via token-level softmax, verbalized statements, or self-consistency sampling — a 2025 survey (Huang et al., arXiv:2503.15850) notes verbalized confidence is often poorly calibrated; (2) **post-hoc calibration**, chiefly temperature scaling (Guo et al., 2017), still a standard baseline in 2025 LLM calibration work (arXiv:2603.09309, arXiv:2604.19444); and (3) **conformal prediction (CP)**, which wraps any confidence function in a distribution-free procedure with a finite-sample coverage guarantee regardless of calibration quality. Recent LLM-specific CP work includes SConU (arXiv:2504.14154), domain-shift-aware CP (arXiv:2510.05566), and MCQA-CP (MIT Media Lab). A key selling point repeated across this literature is that CP's guarantee holds *even for a badly calibrated model* — but papers rarely quantify how much calibration quality affects *efficiency* (set size), or how this compares to the effect of nonconformity-score choice (e.g., LAC vs. APS).

**Gap.** No paper we found cross-tabulates calibration method (raw vs. temperature-scaled vs. ensembled) against conformal score choice (LAC vs. APS), with variance estimates, to ask which factor matters more for prediction-set size. This is the gap we target.

**Our contribution.** A small, reproducible, multi-seed empirical study (~2 minutes on CPU for 10 seeds) that: (a) reproduces the standard finding that temperature scaling fixes ECE while ensembling alone does not, with variance estimates showing the ensembling effect is robust; (b) shows calibration method's effect on LAC conformal set size is statistically indistinguishable from seed noise, versus (c) a large, many-standard-deviation effect from switching LAC→APS; and (d) checks robustness of (b)–(c) under a second, low-noise data regime. We also document a failure mode of LAC (empty prediction sets for ~10% of test points at nominal 90% coverage) masked by mean coverage alone.

**Honesty about scope.** We do not use a pretrained LLM: HuggingFace Hub access in this environment fails with a certificate error (no outbound internet). We instead use a small feedforward network on a synthetic, class-overlapping, label-noised task, explicitly designed to reproduce measurable softmax miscalibration, evaluated with the exact tool stack (ECE, temperature scaling, ensembling, split conformal) used in the LLM literature we surveyed. We treat this as a controlled surrogate, not a claim about any specific LLM's behavior. A second limitation: with one synthetic data-generating family, we cannot rule out that the *specific numbers* are artifacts of this setup, even though Section 3.5 shows the qualitative ranking is stable across two structurally different noise regimes.

## 2. Method

### 2.1 Synthetic task
Six classes in a 20-dimensional feature space, generated from class-specific Gaussian means (fixed across seeds) with per-sample isotropic noise (σ=1.8, main regime) inducing class overlap. Training labels are corrupted with 12% uniform label noise to induce memorization-driven miscalibration (Guo et al., 2017); calibration and test labels are noise-free. Split: 4,000 train / 1,500 calibration / 1,500 test. **Every seed redraws the full split, retrains the base model and all 5 ensemble members from scratch, and refits temperature scaling and conformal thresholds independently** — not resampling from one fixed model.

### 2.2 Models
- **Base model**: one 2-hidden-layer MLP (64 units, ReLU), Adam, max 80 iterations, full-batch.
- **Ensemble**: 5 MLPs of the same architecture, each on an independent bootstrap resample with a different init, combined by averaging softmax outputs — a lightweight surrogate for LLM **self-consistency** sampling, where diversity comes from stochastic decoding rather than bootstrap/init diversity; the aggregation mechanism (averaging independent estimates of the output distribution) is analogous, though we do not claim the surrogate reproduces decoding-time diversity exactly.

### 2.3 Calibration methods and conformal prediction
Four confidence variants (`raw_softmax`, `temp_scaled`, `ensemble`, `ensemble_temp_scaled`), temperature fit by NLL minimization on the calibration split. Split conformal prediction at target coverage 90% (α=0.10) on the held-out test set, using **LAC** (score = 1 − p(true class)) and **APS** (Romano et al., 2020; cumulative sorted softmax mass) nonconformity scores, applied to each of the four confidence methods. We report empirical coverage, average set size, and empty-set fraction (only possible under LAC), each as **mean ± std over 10 seeds**.

## 3. Results

All numbers are mean ± std over 10 independent seeds (`experiment.py` → `results.json`, ~105s total on CPU); a second, lower-noise regime is in `sensitivity.py` → `sensitivity_results.json`.

### 3.1 Calibration quality

| Method | Accuracy | ECE | Fitted T |
|---|---|---|---|
| raw_softmax | 0.997±0.001 | 0.128±0.008 | 1.0 |
| temp_scaled | 0.997±0.001 | 0.078±0.004 | 0.830±0.008 |
| ensemble | 1.000±0.001 | 0.131±0.008 | 1.0 |
| ensemble_temp_scaled | 1.000±0.001 | 0.075±0.004 | 0.816±0.010 |

Temperature scaling reduces ECE by ~40% for both the single model and the ensemble, consistently across all 10 seeds (non-overlapping ±1 std ranges). The fitted temperature is consistently **below 1** (T≈0.82–0.83, tight std) — our base model is mildly **underconfident** rather than overconfident, the opposite of the classic Guo et al. (2017) large-vision-net finding. Section 3.5 shows this is tied to the specific noise/label-corruption regime, not a one-off artifact: in a lower-noise regime the fitted T is ≈0.99 (essentially no correction needed). **Ensembling alone does not improve ECE** — 0.131±0.008 vs. 0.128±0.008, a difference smaller than one standard deviation, so we now describe this as *statistically indistinguishable from no effect* rather than a reliable degradation (softening our earlier single-seed claim that ensembling "worsens" calibration).

### 3.2 Conformal prediction: LAC

| Method | Coverage | Avg. set size | Empty-set frac. |
|---|---|---|---|
| raw_softmax | 0.902±0.011 | 0.902±0.011 | 0.098±0.011 |
| temp_scaled | 0.902±0.011 | 0.902±0.011 | 0.098±0.011 |
| ensemble | 0.899±0.010 | 0.899±0.010 | 0.101±0.010 |
| ensemble_temp_scaled | 0.898±0.010 | 0.898±0.010 | 0.102±0.010 |

All four variants hit target coverage. **The spread of LAC set-size means across the four calibration methods is ≈0.004 — smaller than the ≈0.01 seed-to-seed standard deviation for any single method** — so, corrected from our earlier single-run draft (which understated the spread relative to noise), calibration method's effect on LAC set size is not statistically distinguishable from zero at this sample size. All four LAC variants produce **empty prediction sets for ~10% of test points**, consistent across seeds (std ≈0.01) — a real, reproducible cost hidden by mean coverage. LAC's average set size sits below 1 in all conditions; this near-floor regime (Section 4) means small absolute differences have limited room to manifest.

### 3.3 Conformal prediction: APS

| Method | Coverage | Avg. set size |
|---|---|---|
| raw_softmax | 1.000±0.000 | 2.633±0.077 |
| temp_scaled | 1.000±0.000 | 2.828±0.078 |
| ensemble | 1.000±0.000 | 2.564±0.063 |
| ensemble_temp_scaled | 1.000±0.000 | 2.800±0.072 |

APS never produces empty sets and is markedly more conservative, over-covering the 90% target and averaging 2.6–2.8 of 6 classes. Unlike LAC, calibration method *does* move APS set size by more than one standard deviation (spread ≈0.26 vs. std ≈0.07–0.08): temperature-scaled variants are consistently larger than raw counterparts, replicating our earlier single-seed observation that sharpening the confidence distribution changes APS's cumulative-mass ranking in a way that adds classes here.

### 3.4 Cross-cutting comparison

Holding the score fixed, calibration method moves LAC set size by ≈0.004 (noise-level) and APS set size by ≈0.26 (a real but modest effect, ~3–4 std). Holding calibration method fixed, switching LAC→APS moves set size by **≈1.7–1.9 classes**, roughly **20+ times the seed-to-seed standard deviation** and far larger than either calibration effect — the corrected, variance-aware version of our central claim.

### 3.5 Robustness to the noise regime

To check whether this ranking is an artifact of one synthetic setup, we reran the full pipeline (5 seeds) under a second regime: lower feature-space overlap (σ=0.8) and **zero label noise**. Here the base model is already near-calibrated (ECE≈0.004, fitted T≈0.99 — confirming the T<1 underconfidence in Section 3.1 is a consequence of the label-noise recipe, not a fluke), so calibration has little room to act. The LAC-vs-calibration spread stays tiny (≈0.005) and the LAC-vs-APS score-choice gap, while smaller (≈1.37 vs. ≈1.81 classes), remains dominant by a wide margin — supporting score choice as the dominant factor across two structurally different regimes, though a systematic sweep (varying σ, label noise, class count toward LLM-scale vocabularies) remains future work.

## 4. Discussion and Limitations

The central finding — conformal score choice matters far more than calibration method for prediction-set efficiency — is now grounded in seed-level variance rather than a single run, and holds under a second noise regime. It helps explain why LLM-focused CP papers invest in designing better nonconformity scores rather than upstream calibration. We do not claim this is a novel structural discovery about LAC/APS (their small/empty-set vs. conservative/adaptive behavior is documented in the CP literature); our contribution is quantifying the relative magnitude, with uncertainty estimates, on a controlled task.

Limitations, ordered by how directly they threaten our claims: (1) we could not access a pretrained LLM (HuggingFace Hub SSL failure in this sandbox); all experiments use a synthetic surrogate, so specific numbers should not be read as LLM benchmarks, though the qualitative ranking (coverage is calibration-robust; LAC vs. APS differ sharply) is a property of the conformal procedures themselves and should transfer. (2) LAC's average set size sits below 1 in every condition tested; this floor effect means our "calibration doesn't move LAC size" finding partly reflects a metric with little room to move, and should be re-examined at other target coverage levels (80%, 95%) or lower-accuracy tasks. (3) We used vanilla APS rather than regularized APS (RAPS), commonly used to control APS's large set sizes; whether RAPS narrows the LAC/APS gap is untested here. (4) Our self-consistency-via-bootstrap-ensembling surrogate is imperfect — LLM self-consistency diversity comes from stochastic decoding, not bootstrap/init diversity — so the ensembling-does-not-calibrate finding should be read as a property of this aggregation mechanism, not a decoding-time LLM claim.

## 5. Conclusion

Across 10 seeds, temperature scaling reliably reduces pointwise calibration error (~40% ECE reduction, consistent across seeds) while naive ensembling does not, with no evidence it degrades calibration once seed noise is accounted for. Neither calibration intervention moves LAC conformal set size beyond seed-to-seed noise, while the choice of nonconformity score (LAC vs. APS) moves set size by roughly 20+ standard deviations — an effect that persists across two different noise regimes. LAC's ~10% empty-set rate at nominal 90% coverage is a real, reproducible cost that raw coverage numbers hide. Practitioners building LLM systems around conformal guarantees should prioritize nonconformity-score selection (and check empty-set rates) over investing purely in calibration quality, since coverage validity is calibration-agnostic by construction but efficiency and set-emptiness are not.
