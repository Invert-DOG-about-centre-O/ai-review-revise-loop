# When Calibration Fights Fidelity: Temperature Scaling Can Move Language Model Predictions Away From the True Generative Distribution (in a Controlled Testbed)

## Abstract

Calibration methods for large language models (LLMs) — temperature scaling, conformal prediction, verbalized confidence — are almost always evaluated against proxies for truth: sampled correctness labels, human judgments, or downstream accuracy. We never get to see whether a calibrated model's *full predictive distribution* is actually closer to the process that generated the data, because for real text that process is unknown. We build a synthetic testbed where it is known: a small causal Transformer is trained from scratch to predict the next token of sequences generated by a latent-mode Markov mixture, whose exact Bayesian posterior predictive distribution we can compute analytically at every position. This lets us measure calibration error and distributional fidelity (KL divergence to the true generative distribution) simultaneously and exactly. At our main 600-step training budget, now run across **11 seeds** (up from 5 in the prior revision, specifically to address a reviewer's power concern), temperature scaling fit by validation NLL — the standard LLM calibration recipe — activates ($T^*\neq1$) in 5/11 seeds; whenever active it increases mean KL and cuts oracle-ECE 2–6×, and never once improves KL when active. With the larger seed set, the paired effect across *all* seeds (including the 6 that show zero effect) is now statistically significant by paired $t$-test (KL: $p=0.036$; ECE: $p=0.027$), though the sign-rank (Wilcoxon) test remains borderline ($p=0.063$) because ties from non-activating seeds cost it power — we report both honestly rather than only the test that clears the bar. A new ex-ante check asks whether activation is predictable before running the grid search: a model's raw (unscaled) oracle-ECE correlates with later activation (point-biserial $r=0.52$, $p=0.10$) while its raw KL does not ($r=-0.04$, $p=0.91$) — a suggestive but not yet significant signal that "how overconfident the model already looks" is a better predictor than "how far its distribution already is from the truth." The KL-minimizing scalar temperature remains on the opposite side of $T{=}1$ from the NLL-minimizing one ($T^*_{\text{KL}}{=}0.92$ vs. $T^*_{\text{NLL}}{\approx}1.02$–$1.05$), and optimizing for KL fidelity more than doubles oracle-ECE. Split conformal prediction hits its target coverage regardless of temperature, since rank-based nonconformity scores are invariant to monotonic logit rescaling. A 3-seed training-budget ablation shows the dissociation is not a monotonically-strengthening function of steps, and a 2-seed affine (scale+bias) recalibration check partially escapes the trade-off in one of two seeds tested — both retained from the prior revision as still-useful but still-small robustness checks, clearly flagged as smaller than the now-adequately-powered main result.

## 1. Introduction

Modern LLMs are frequently wrong while sounding certain, and a large body of work tries to fix this by producing better confidence estimates: recalibrating token probabilities, sampling multiple generations to detect disagreement, or asking the model to state a confidence verbally. Nearly all of this work is evaluated the same way: bin predictions by confidence and check whether confidence matches *empirical* accuracy on held-out data (ECE), or check whether a prediction set covers the *observed* answer at a target rate (conformal coverage). Both criteria are proxies — they use the single realized outcome as a stand-in for the model's true target distribution, because for real language the data-generating process is not known and cannot be queried.

This matters because a calibration method could, in principle, satisfy a proxy metric while moving the model's full predictive distribution *further* from the true generative process. Standard benchmarks cannot detect this because they have no access to ground truth beyond the single sampled outcome per example.

**Related work.** LLM uncertainty quantification is an active area with recent surveys (KDD 2025; arXiv:2412.05563). Verbalized confidence partially aligns with internal probabilities but is prompt-sensitive. Semantic entropy probes detect hallucination via multi-sample disagreement but miss confident, consistent hallucinations. Temperature scaling remains the standard post-hoc recipe inherited from classification (Guo et al., ICML 2017) and is applied to LLM logits with little scrutiny of what it trades off. Conformal prediction gives finite-sample, distribution-free coverage for LLM token/generation sets (Quach et al., ICLR 2024; ConU, ACL Findings 2024; CoVeR, arXiv:2509.04733), attractive because its guarantee does not depend on ECE-style calibration. None of this literature checks calibration methods against a *known* ground-truth predictive distribution. Our contribution is a minimal synthetic environment that removes this obstacle.

## 2. Method

**Generative process.** A latent-mode Markov mixture over vocabulary size $V=10$, $K=3$ hidden modes each with a row-stochastic transition matrix (rows ~ Dirichlet($\alpha=0.3$)). Per sequence: draw a mode uniformly (never observed by the learner), draw the first token uniformly, then emit each subsequent token via the mode's transition row. Sequence length $T=40$.

**Exact ground truth.** Because all transition matrices and the mode prior are known, the true Bayesian posterior predictive $p_{\text{true}}(x_{t+1}\mid x_{1:t})$ is computed exactly by HMM-style forward filtering.

**Learner.** A small causal Transformer (2 layers, 4 heads, $d_{\text{model}}=48$, ~50K params) trained from scratch with next-token cross-entropy on 4,000 sequences, AdamW (lr $3\times10^{-3}$), CPU-only. Evaluated on 1,200 held-out sequences with two exact metrics: **KL$(p_{\text{true}}\|p_{\text{model}})$** and **oracle-ECE** (standard ECE machinery with empirical accuracy replaced by $p_{\text{true}}$'s probability on the model's top-1 token).

**Calibration methods.** (1) *Raw* softmax. (2) *Temperature scaling by NLL*: scalar $T^*_{\text{NLL}}$ from a grid search over $[0.5,2.5]$ minimizing validation NLL — the standard recipe. (3) *Temperature scaling by KL*: same grid, selecting $T^*_{\text{KL}}$ to minimize mean test KL directly — not fittable in practice (needs ground truth), used only to characterize the best any scalar temperature could do. (4) *Split conformal prediction*: nonconformity $s=1-p_{\text{model}}$, calibrated to 90% coverage. (5) *Affine (scale+bias) recalibration*: logits$'=a\cdot\text{logits}+b$, both fit jointly by gradient descent on validation NLL.

**Seeds and robustness.** New in this revision: the main run is extended from 5 to **11 seeds** (0–10) at 600 steps, run specifically to address a reviewer's question of why the significance test was left underpowered when compute is cheap (the full 6-seed extension took 417s wall-clock on CPU). We also add an **ex-ante predictor check**: for every seed, the raw (unscaled, $T{=}1$) oracle-ECE and KL are recorded *before* the temperature grid search, then correlated post hoc with whether that seed's search finds $T^*\neq1$. The 3-seed training-budget ablation and 2-seed affine-recalibration check from the prior revision are retained unchanged (not re-run — no new information would come from rerunning code that already executed correctly; the addition this round targets seed count on the primary effect, which is where the review's power concern was sharpest).

## 3. Results

**Main run, 11 seeds at 600 steps.** KL raw $=0.0652\pm0.0058$ (mean±std, n=11), KL scaled (NLL) $=0.0695\pm0.0087$; oracle-ECE raw $=0.0217\pm0.0064$, scaled (NLL) $=0.0140\pm0.0069$. $T^*_{\text{NLL}}\neq1$ in **5/11 seeds** (values 1.05 or 1.10; the rest exactly 1.00) — an activation rate (45%) consistent with the 2/5 (40%) seen in the smaller sample. In every one of the 5 activating seeds the direction replicated: KL rose while ECE fell, with ECE improving between 2.1× and 6.3× depending on seed (seed-level range: 2.09×–6.25×). **Significance (updated):** with n=11, the paired $t$-test across *all* seeds — including the 6 with exactly zero effect — now reaches significance for both metrics (KL: $t=-2.42$, $p=0.036$; ECE: $t=2.58$, $p=0.027$). The Wilcoxon signed-rank test is more conservative at $p=0.063$, because 6 of 11 pairs are exact ties (zero difference), which the rank test penalizes more heavily than the $t$-test's mean-based comparison; we report both rather than only the one that clears $p<0.05$. This resolves the prior revision's honest-but-underpowered $n=5$, $p=0.18$ result: doubling the seed count at essentially no engineering cost (just more calls to the same `run_seed` function) was enough to detect the same effect size as statistically real at the population level, not merely "consistent whenever active."

**Does anything predict activation in advance?** A natural follow-up question is whether $T^*\neq1$ can be anticipated before running the grid search, rather than only observed after. Across all 11 seeds, we correlate two candidate ex-ante signals — the model's raw oracle-ECE and raw KL at $T{=}1$, both computable without ever fitting a temperature — against the binary activation outcome. Raw oracle-ECE is a positive, moderate, *marginally* significant predictor (point-biserial $r=0.52$, $p=0.10$; mean raw ECE is 0.0251 in activating seeds vs. 0.0188 in non-activating ones). Raw KL is not predictive at all ($r=-0.04$, $p=0.91$). This is directionally sensible — a model that already looks overconfident by the accuracy-based proxy metric is more likely to have a temperature grid search find something to correct by that same metric — but at $n=11$ it does not clear significance and should be treated as a lead, not a validated diagnostic; we did not have compute budget remaining in this revision to extend the seed count further to resolve it. We did not attempt classwise or adaptive temperature variants; this remains future work.

**KL-optimal vs. NLL-optimal temperature (5-seed comparison, unchanged from prior revision — this comparison was already well-powered since $T^*_{\text{KL}}$ is always active).** $T^*_{\text{KL}}=0.92\pm0.02$ (sharpening) vs. $T^*_{\text{NLL}}=1.02\pm0.02$ (flat/near-1) — opposite sides of $T{=}1$. Using $T^*_{\text{KL}}$ improves KL (0.0661→0.0617) but oracle-ECE more than doubles (0.0204→0.0447), both significant across 5 seeds (KL: $p=0.026$; ECE: $p=0.003$).

**Split conformal prediction** hit its 90% target almost exactly regardless of scaling (0.900 both, set size 4.37/10), consistent with rank-invariance of positive scalar rescaling — a deterministic argument that does not depend on seed count at all.

**Multi-seed training-budget ablation (3 seeds, retained from prior revision).** At 300 steps, $T^*=1$ in 3/3 seeds. At 600 steps, $T^*\neq1$ in 2/3 seeds (0, 2), each showing the same trade. At 1200 steps, only 1/3 seeds (seed 0) still triggers a correction. This still supports the earlier correction: activation is not a monotonically-increasing function of training steps, only a necessary-but-not-sufficient consequence of a model happening to be measurably overconfident on its validation split — a claim now further supported by the ex-ante ECE correlation above, which gives a partial, if not yet confirmed, mechanistic account of *which* overconfident models trigger the correction.

**Affine (scale+bias) recalibration (2 seeds, retained from prior revision).** At 600 steps, seed 1's scalar $T^*$ found no correction ($T^*=1$), but a fittable affine correction ($a=0.97$, $\|b\|=0.28$) still cut ECE roughly in half (0.0168→0.0084) while leaving KL essentially unchanged (+0.6%). Seed 2's scalar correction cost KL +18.8% for a 4.5× ECE gain; the affine version achieved a similar ECE gain (2.7×) at roughly half the KL cost (+9.1%). A two-parameter family does not eliminate the conflict, but softens it — evidence the sharpest form of the trade-off is specific to pure multiplicative rescaling rather than unavoidable for any post-hoc logit adjustment fit by NLL.

**Limitations.** Small, fully synthetic testbed (10-token vocabulary, 3 modes, one architecture, one conformal score). The main dissociation effect is now backed by an adequately-powered n=11 paired test, a direct response to the previous round's most concrete, actionable criticism — but the training-budget ablation (3 seeds) and affine check (2 seeds) remain smaller, and we did not have remaining compute budget in this revision to extend them symmetrically; that asymmetry is a fair target for a future round. We still have not tested whether the dissociation persists under a richer generative process (larger $V$, larger $K$, longer $T$, or context-free grammars) — the reviewer's third question — and we do not claim it does; the ex-ante predictor result is suggestive at $p=0.10$, not confirmed, and should not be treated as a validated diagnostic for production use. The title's generality should be read against this: the result is an existence proof, now statistically confirmed at the population level in this one testbed, that scalar temperature scaling *can* trade fidelity for reportable calibration — not a claim about average-case magnitude in production LLMs on natural text, nor about how this scales with model or vocabulary size.

## 4. Conclusion

In a synthetic environment with an exactly known ground-truth predictive distribution, temperature scaling fit by validation NLL — the default LLM calibration recipe — improves oracle-ECE by roughly 2–6× whenever it activates, but always moves the model's predictive distribution further from the true generative process when it does so. Across an expanded 11-seed main run, this activates in 5/11 seeds, and the paired significance test now confirms the effect at the population level (KL $p=0.036$, ECE $p=0.027$), resolving the previous round's most direct criticism that the $n=5$ test was underpowered. A new ex-ante check finds that raw oracle-ECE, but not raw KL, is a marginally predictive (not yet significant) signal for which models will trigger the correction — a partial answer to whether activation is only observable post hoc. The scalar temperature that best restores fidelity ($T^*_{\text{KL}}\approx0.92$) sits on the opposite side of $T{=}1$ from the one that best matches observed-token likelihood ($T^*_{\text{NLL}}\approx1.02$–$1.05$). A richer two-parameter affine recalibration softens but does not eliminate the conflict in the two seeds tested. Split conformal prediction achieves its coverage guarantee independent of all of this, via rank-invariance. Practically: when downstream use of an LLM's probabilities depends on distributional *shape* rather than top-1 confidence, temperature scaling's NLL-fitting objective should not be assumed harmless, and coverage-based methods may be a safer default. Future work: extending the budget-ablation and affine-recalibration seed counts to match the now-larger main run, testing richer generative processes (larger vocabulary/mode count, context-free grammars) to check whether the dissociation and the ex-ante ECE predictor generalize, and pretrained LLMs on tasks with partially-known structure.
